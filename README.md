# EverHASH

EverHASH is an experimental, open-source proof-of-work blockchain project derived from Raven Core. The project is currently in early development; network parameters and wallet formats may change before any public launch.

## Project status

This repository is a development prototype, not a production-ready cryptocurrency release. The consensus changes have only had limited local validation. Do not use it to store funds or assume that any network launched from this code will be stable, secure, or supported.

Before inviting public miners, the project still needs independent consensus review, reproducible builds, longer multi-node testing, public seed nodes, and documented wallet and recovery procedures. The mainnet genesis block is already fixed in the current source; changing it later would create a different network.

## Build and run

Build instructions are being adapted from the upstream Raven Core documentation. See [`doc/`](doc/) for existing platform-specific notes. Those documents may still refer to Raven names and settings; check all network and wallet options carefully before use.
